# FASTCUT.lsp

> **AutoCAD / progeCAD 雷射切割專用：大面積網格邊界極速裁切與自動封閉工具**
> High-performance Grid Trimming & Boundary Auto-Closing Tool for Laser Cutting.

---

## 📌 簡介 (Introduction)

在雷射切割（Laser Cut）製程中，經常需要在不規則外框內部排列大量網格或幾何孔洞（如 1mm/2mm 方孔、圓孔、六角蜂巢孔等）。

傳統做法的痛點：
1. **`EXTRIM` 缺陷**：只能單個手動點選，且裁切後邊界格子會形成**缺口破線（未閉合）**，雷切無法成形。
2. **手動修補耗時**：遇到數百至數萬個小孔時，手動補線極耗工時。
3. **容易產生重疊線**：導致雷射重複切割、材料燒焦。

**`FASTCUT.lsp`** 採用「反向遮罩差集運算」技術：
* ⚡ **極速批次處理**：數百到上萬個孔洞，只需 **1 次選取、2~5 秒內完成**。
* 🔒 **自動密封（Closed Polyline）**：被幾何外框切到的邊緣孔洞，**100% 自動沿著外框補線封閉**。
* 🔷 **支援任意幾何形狀**：正方形、長方形、圓形、橢圓、六角蜂巢孔、菱形、星形或自訂異形皆通用。
* 🔄 **面域自動轉聚合線**：裁切後自動由 Region 轉為封閉 Polyline，完美銜接雷切軟體路徑。
* 🗑️ **自動刪除外框**：運算完成自動清除外框，免手動清理。
* 🛡️ **保護 Snap 設定**：全程使用無鎖點模式，絕對不關閉、不重置使用者的物件鎖點（OSMODE）。
* ⌨️ **支援超短快捷鍵**：支援 `FC` 或 `FTC`，左手盲打極速下單。
* 💻 **雙平臺支援**：相容 **AutoCAD** 與 **progeCAD**。

## 🚀 快速上手 (Quick Start)

### 1. 載入外掛
* **直接拖曳**：將 `FASTCUT.lsp` 檔案直接拖入 AutoCAD / progeCAD 繪圖視窗放開。
* *(或使用 `APPLOAD` 指令載入)*

### 2. 執行快捷鍵
在指令列輸入快捷鍵（二選一）：
```text
FC     (推薦，超短快捷鍵)
或
FTC
或
FASTCUT
```

### 3. 操作流程
1. `請點選【外圍的大幾何外框】:` ➔ **點選封閉幾何大外框**。
2. `請框選【所有格子】:` ➔ **滑鼠框選全部的網格/幾何孔洞**，按 **Enter**。
3. **完成！** 外框自動清除，所有孔洞（包括被切邊的）100% 密封為 Closed Polyline。

## ⚠️ 使用前提要求與注意事項 (Prerequisites & Tips)

### 🔴 重要前提要求（Prerequisites）
1. **外框必須是封閉幾何（Closed）**：
   * 外圍大幾何外框必須是閉合的封閉多邊形。
   * *💡 若外框線條不平整或無法建立面域，可在內部空白處輸入 `BO`（邊界指令）點一下重繪乾淨外框。*
2. **小孔/小格子必須是「獨立且封閉的個體」**：
   * 不管是正方形、圓形、六角形、菱形還是自訂異形，每個小孔必須是**單一封閉物件（Closed Polyline / Circle）**，不能是由 4 條各自散開的獨立直線（Line）拼成。
   * 若小孔是用 `ARRAY`（陣列）排出來的，請務必先框選輸入 **`X`（`EXPLODE`）分解一次**，讓它們變成各自獨立的封閉幾何。

---

### 💡 雷切加工建議 (Laser Cut Tips)
1. **1mm 孔洞引刀線設定**：
   * 孔洞小於 2mm 時，請將雷切軟體的引刀線（Lead-in）設為 `0` 或中心穿刺，避免起刀時爆孔炸穿薄壁。
2. **啟用「飛切 (FlyCut)」**：
   * 大面積密集微孔建議搭配雷切機軟體（如 CypCut / LightBurn）的 **「網格飛切 / 連續飛切」** 功能，可大幅降低材料熱變形，加工速度提升 10 倍以上。
